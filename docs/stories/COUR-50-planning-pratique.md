# COUR-50 — Planning pratique et rassurant

## Story

En tant qu'utilisateur, je veux préparer toute ma semaine en quelques gestes,
afin d'obtenir rapidement une liste de courses utile sans remplir un formulaire.

## Critères d'acceptation

- [x] « Compléter avec mes favoris » remplit midi et soir, sans écraser les décisions existantes.
- [x] Deux recettes identiques ne se suivent pas si plusieurs favoris existent.
- [x] Les favoris sont répartis équitablement sur la semaine.
- [x] Toucher un repas ouvre son remplacement; une action séparée permet de le retirer.
- [x] La dernière action, y compris un remplissage multiple, peut être annulée.
- [x] Une progression claire indique les créneaux décidés sur 14.
- [x] Toutes les cibles tactiles nouvelles font au moins 44 points et possèdent un libellé accessible.
