# COUR-72 — Comparer les paniers par enseigne

## Story

En tant que testeur, je veux comparer le panier recommandé avec les alternatives
SwissGroceries afin de choisir le compromis qui me convient.

## Critères d'acceptation

- les plans primaire et alternatifs sont conservés ;
- chaque option affiche le nombre d'enseignes et son total indicatif ;
- la sélection choisie alimente le brouillon modifiable ;
- aucune économie n'est affirmée sans référence mono-enseigne comparable.
