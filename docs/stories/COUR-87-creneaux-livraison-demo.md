# COUR-87 — Créneaux de livraison simulés

## Objectif

Tester le choix d’une livraison par enseigne sans suggérer une disponibilité
marchande réelle.

## Critères d’acceptation

- deux jours et trois périodes sont générés de façon déterministe ;
- la préférence matin/après-midi/soir présélectionne un créneau ;
- chaque enseigne possède son choix indépendant et accessible ;
- le créneau est conservé dans l’instantané de démonstration ;
- le texte indique toujours que le créneau est simulé.
