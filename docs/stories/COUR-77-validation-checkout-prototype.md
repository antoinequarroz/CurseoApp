# COUR-77 — Validation du checkout prototype

## Story

En tant que testeur, je veux parcourir le checkout de démonstration de bout en
bout afin d'identifier les blocages avant le prochain TestFlight groupé.

## Critères d'acceptation

- un protocole couvre succès, chargement, erreur, vide et reprise ;
- le parcours n'envoie aucune commande et ne débite aucun moyen de paiement ;
- les contrôles automatisés couvrent les transformations métier critiques ;
- aucun build TestFlight n'est déclenché par ce ticket.
