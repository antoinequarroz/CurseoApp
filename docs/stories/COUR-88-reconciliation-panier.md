# COUR-88 — Réconciliation du panier

## Objectif

Présenter avant le checkout les écarts entre les besoins et les produits trouvés.

## Règles

Points bloquants : correspondance incertaine non confirmée et quantité inférieure
au nombre de paquets requis. Avertissements : format inconnu, disponibilité non
confirmée, doublon possible et produit introuvable.

## Critères d’acceptation

- les problèmes sont regroupés dans un résumé lisible ;
- un produit incertain peut être confirmé explicitement ;
- le CTA livraison reste désactivé tant qu’un blocage subsiste ;
- un lien direct vers le checkout ne contourne pas cette garde ;
- les avertissements seuls ne bloquent pas la démonstration.
