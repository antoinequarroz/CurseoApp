# COUR-78 — Correspondances produit compréhensibles

## Story

En tant que testeur, je veux comprendre la qualité d'une correspondance et le
nombre de paquets estimé afin de corriger rapidement un panier imparfait.

## Critères d'acceptation

- le besoin initial, le format, le nombre de paquets et le prix unitaire sont visibles ;
- une correspondance faible demande une validation manuelle ;
- le calcul d'unités est déterministe et testé ;
- le score est présenté comme une estimation coursIA, jamais comme un score marchand.
