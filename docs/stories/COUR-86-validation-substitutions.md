# COUR-86 — Validation des substitutions

## Objectif

Éviter qu’un tap remplace silencieusement un produit.

## Critères d’acceptation

- sélectionner une proposition ne modifie pas encore le panier ;
- l’ancien et le nouveau produit sont comparés ;
- le coût total, le nombre de paquets et le changement d’enseigne sont visibles ;
- une hausse dépassant la préférence est signalée ;
- seul le bouton « Confirmer ce remplacement » applique le changement.
