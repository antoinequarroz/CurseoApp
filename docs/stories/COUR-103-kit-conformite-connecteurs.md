# COUR-103 — Kit de conformité des connecteurs marchands

## Objectif

Tester tous les futurs adaptateurs Migros/Coop contre le même contrat avant leur activation.

## Contrôles

- capacités panier, livraison et commande déclarées;
- simulation sans paiement ni transmission;
- panier idempotent pour une même clé;
- parcours stock, livraison et préparation complet;
- résultat cohérent avec le mode annoncé;
- annulation disponible.

Le jeu d'essai utilise uniquement des identifiants fictifs et ne conserve aucune PII.
